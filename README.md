# Customer Support Chatbot 🤖

This is a **Customer Support Chatbot** built using **Dialogflow** as part of my internship project with [Future Interns](https://futureinterns.com). The chatbot is designed to assist users by answering FAQs, providing support, and operating 24/7—just like the virtual assistants used by Amazon, Flipkart, and Zomato.

---

## 🌟 Features

- **Greeting Message:** Welcomes users with a friendly message like "Hi! How can I help you?"  
- **FAQ Responses:** Answers common customer queries such as order tracking, returns, and product information.  
- **Fallback Responses:** Handles queries it doesn’t understand and guides the user appropriately.  
- **Optional Integrations:** Can be connected to Telegram, websites, or tools like Airtable/Notion for real support tickets.  

---

## 🛠 Tools Used

- Dialogflow (https://dialogflow.cloud.google.com/) – No-code AI chatbot builder  
- Telegram Bot API(https://core.telegram.org/bots) – For live chat integration  

---

- Understanding **how AI chatbots work** on websites and messaging platforms.  
- Designing **realistic conversational flows** and responses.  
- Implementing **smart fallback messages** for unrecognized queries.  
- (Optional) Connecting AI assistants with **external tools and live platforms**.
